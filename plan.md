Pada proyek ini, saya akan membuat sebuah Todo App sederhana untuk belajar cloud computing yang dimana proyek ini akan dihosting dan di konfigurasi dengan web server, application server, dan database server dengan menggunakan proxmox, dan menggunakan tools docker yang bisa digunakan untuk membangun container yang berisi aplikasi dan database dalam 1 command.

Server yang dibangun yaitu
Nginx
PHP, nodejs
mysql/mariadb

proyek laravel saat ini masih kosong, terdapat halaman register dan login yang sudah tersedia dan tambahkan fitur todo dengan CRUD
